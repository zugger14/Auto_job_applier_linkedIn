## 2. How to Run and Monitor the Bot

I have created an all-in-one script called `start_job_bot.sh` that automates the startup process.

> [!TIP]
> **What this script does:**
> 1. Activates your Python virtual environment.
> 2. Starts the **Web Dashboard** in the background so you can monitor progress visually.
> 3. Starts the **Main AI Bot** in the foreground so you can watch the real-time logs.

### Running the Script

1. Open your terminal.
2. Navigate to the project directory:
   ```bash
   cd ~/vibe-coding-apps/Auto_job_applier_linkedIn
   ```
3. Run the startup script:
   ```bash
   ./start_job_bot.sh
   ```

### Monitoring Your Applications

Once the script is running, you can monitor the bot in two ways:

1. **The Terminal Logs:** The terminal will actively print out what the bot is doing, which company it is looking at, if it skipped a job (and why), and the responses generated by Gemini.
2. **The Visual Dashboard:** Open your web browser and go to **[http://localhost:5000](http://localhost:5000)**. This dashboard will show you a history of every job successfully applied to, including links to the job postings.

> [!WARNING]
> **Safety First:** LinkedIn strictly prohibits bots. To avoid getting your account banned, the bot operates at a human-like speed with random delays. Do not run it 24/7. Run it for a few hours a day, and always monitor the terminal logs for the first few runs to ensure it's behaving exactly how you want.

## 3. How to Switch to China On-Site Mode

By default, the bot is configured for **Worldwide Remote** roles. When you want to run a batch specifically for roles in **China** (where you are willing to work On-Site but require Visa Sponsorship), you must manually update your config files before running `start_job_bot.sh`.

**Step 1: Update `config/search.py`**
Open the file and modify these two lines to target China and On-site/Hybrid roles:
```python
search_location = "China"
on_site = ["On-site", "Hybrid"]
```

**Step 2: Update `config/questions.py`**
Open the file and modify the visa requirement (since you will need sponsorship to work in China):
```python
require_visa = "Yes"
```

Once you've made those changes and saved both files, you can run `./start_job_bot.sh` again and it will begin targeting China-based roles! When you want to switch back to Worldwide Remote, just revert those settings to `"Worldwide"`, `["Remote"]`, and `"No"`.
